# 🏃 와이즈러너스 러닝 트래커

러닝 동호회를 위한 **카카오톡 챗봇 + 웹/모바일 앱(PWA)** 통합 트래커입니다.
회원이 러닝 기록 **사진을 보내면 AI(비전 모델)가 자동으로 거리·시간·페이스 등을 추출**해 저장하고,
점수를 매기고, 랭킹·좋아요·상점·마라톤 대회 일정 등 부가 기능을 제공합니다.

---

## ✨ 주요 기능

- **사진 기반 기록 자동 등록**: 러닝 앱 캡처를 보내면 비전 모델이 분석해 기록을 저장 (카카오톡 / 웹 채팅 둘 다)
- **점수 체계**: 데일리(거리·시간) + 주간 보너스 + 대회/동호회 참가 점수
- **러닝 피드 & 좋아요**: 회원들의 최근 기록을 보고 ❤️ 누르기
- **러닝 상점**: 모은 점수로 상품 구매 신청 → 관리자 승인(완료) 시 차감 (쿠팡 검색 링크 제공)
- **마라톤 대회 조회**: 전국 마라톤 일정 크롤링(하루 1회 캐시), 지역(서울·경기) 필터, D-day·접수상태 정렬
- **공지사항 / 자료실**: 공지, 점수 기준, 앱 설치 안내 + 파일 업로드/다운로드
- **관리도구**: 대시보드·랭킹, 사용자별 점수 상세, 대회 참가 등록, 구매 승인/취소 (관리자 비밀번호 보호)
- **복약 기록**: 약 이름·복용량·날짜·시간·메모를 앱 안에서 직접 추가/수정/삭제 (본인만 조회, 점수와 무관)
- **PWA**: 폰 홈 화면에 추가하면 앱처럼 사용 (안드로이드/아이폰) — 테스트용 별도 이름 설치본 제공(`/install-test`)

## 🛠 기술 스택

- **Python 3.10+** (3.12 에서 개발)
- **FastAPI** + **Uvicorn** (웹 서버)
- **Jinja2** (서버 사이드 템플릿)
- **Pydantic** (데이터 검증)
- 데이터 저장: **JSON 파일** (별도 DB 불필요)
- 사진 분석: 외부 **OpenAI 호환 비전(VL) 모델 서버** (config 로 지정)

## 🚀 설치 & 실행

### 1) 클론 & 가상환경
```bash
git clone <레포 주소>
cd running

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2) 설정 파일 생성
```bash
cp config.yaml.example config.yaml
```
그 다음 `config.yaml` 을 열어 값을 채웁니다.

| 항목 | 설명 |
|---|---|
| `connect.ip` / `connect.port` | 러닝 사진을 분석할 **비전 모델 서버** 주소 (OpenAI 호환 `/v1/chat/completions`) |
| `connect.model_name` | 사용할 비전 모델 이름 |
| `connect.api_token` | 모델 서버 API 토큰 (없으면 `null`) |
| `admin.password` | 관리도구의 관리자 비밀번호 (삭제·구매완료·공지작성 등) |

> ⚠️ `config.yaml` 에는 토큰/비밀번호가 들어가므로 **git 에 올리지 않습니다**(`.gitignore` 처리됨).

> 🔒 **공개 저장소 보안 주의**
> 이 저장소는 공개(public)입니다. 과거에 `config.yaml` 이 노출됐거나 커밋 이력에 남아 있다면,
> **반드시 API 토큰을 재발급하고 관리자 비밀번호(`admin.password`)를 변경하세요.**
> 절대 실제 토큰/비밀번호를 커밋하지 말고, 항상 `config.yaml.example` 만 공유합니다.

### 3) 실행
```bash
python main.py
```
기본적으로 `http://0.0.0.0:5000` 에서 구동됩니다. (브라우저에서 `http://localhost:5000/manage` 접속)

또는 종료 후 재기동까지 한 번에 (macOS/Linux):
```bash
bash start.sh        # 포트 5000의 기존 서버 종료 → 백그라운드 재기동(로그: running.log)
```
`start.sh` 는 스크립트 위치 기준으로 동작하며, 가상환경(`.venv`/`venv`)이 있으면 그걸, 없으면 `python3` 를 사용합니다.

> `data/` 폴더와 JSON 파일들은 처음 실행 시 자동 생성됩니다.

## 🌐 외부 공개 / 카카오 연동 (선택)

카카오톡 챗봇이나 외부 폰에서 쓰려면 공개 HTTPS 주소가 필요합니다. 개발/소규모 운영은 **ngrok** 으로 충분합니다.

```bash
ngrok http 5000
```
- 발급된 `https://xxxx.ngrok-free.app` 주소를 사용
- **카카오 챗봇**: 스킬 서버(웹훅) URL 을 `https://xxxx.../` (POST) 로 등록
- 챗봇은 사진/텍스트를 보내면 위 `POST /` 로 들어와 처리됩니다

## 🏆 점수 체계 요약

- **데일리 포인트**(사진 1건, 하루 1회): 거리·시간 조건 중 가장 높은 1개 (10km↑ 50 … 1km↑ 43)
- **주간 보너스**: 한 주 누적 거리/시간 달성 중 가장 높은 1개 (최대 +1000)
- **참가 포인트**: 정기 동호회 +300 / 풀코스 +2000 / 하프 +1500 / 10K +1000
- **러닝 상점**: 점수로 상품 구매(차감) — 신청 후 관리자 완료 시 차감

수요일에 올린 그날 기록은 챗봇이 "정기 동호회 참석?"을 물어보고, "예" 답하면 +300이 추가됩니다.
점수 기준은 `utils/score.py` 한 곳에서 관리되며 공지/안내에 자동 반영됩니다.

## 🗂 데이터 저장

모든 데이터는 `data/` 폴더의 JSON 파일에 저장됩니다 (별도 DB 없음).

| 파일 | 내용 |
|---|---|
| `records.json` | 러닝 기록 (user_id + 날짜 복합키, 동시쓰기 파일락) |
| `user_mapping.json` | user_id ↔ 이름 |
| `events.json` | 동호회/대회 참가 |
| `purchases.json` | 구매 신청/완료 |
| `likes.json` | 피드 좋아요 |
| `notices.json` | 관리자 공지 |
| `medicines.json` | 복약 기록 (본인만 조회/수정) |
| `marathons.json` | 크롤링된 마라톤 일정 캐시 |
| `pending_club.json` | 수요일 동호회 확인 대기 상태 |
| `uploads/` | 자료실 업로드 파일 |

## ⚠️ 참고 / 한계

- **사진 분석 정확도**는 비전 모델 성능과 캡처 화면에 따라 달라집니다. 거리·시간만 인식되면 저장됩니다.
- **마라톤 일정**은 외부 사이트(roadrun.co.kr) HTML 을 파싱하므로 사이트 개편 시 깨질 수 있습니다.
- 인증은 **관리자 비밀번호 + 기기 쿠키** 수준의 가벼운 방식입니다(내부 동호회용).
- JSON 파일 기반이라 대규모 동시 트래픽에는 적합하지 않습니다.
